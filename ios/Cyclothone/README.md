# Cyclothone iOS

Native SwiftUI mobile client for Cyclothone.

- iPhone and iPad target
- Secure Google/GitHub OAuth through ASWebAuthenticationSession
- Email/password and magic-link authentication
- Keychain-backed session tokens
- Existing Cyclothone customer mobile workspace
- Custom callback: cyclothone-ios://auth/callback

App Store signing/distribution is intentionally not configured in this development block.
